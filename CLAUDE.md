# projekt-board

React Kanban-Board fuer Sound-Spirit Team. Ilona, Frank, Christina sehen Aufgaben im Browser.

## Stack
React 18 + Vite + GitHub Pages. Kein Server. localStorage fuer Daten.

## Regeln
- Aufgaben haben: titel, prio (MUST/SHOULD/COULD), ice (Score), status, wer, deadline
- Drag&Drop zwischen Spalten (offen/aktiv/erledigt)
- Mobile-first (Grid wird zu 1 Spalte unter 768px)
- Daten in src/data/storage.js (Default-Tasks aus OFFENE-AUFGABEN.md)
